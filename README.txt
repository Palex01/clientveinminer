Client Vein Miner (Fabric, Minecraft 26.3, Loader 0.20.0)
==========================================================
Baut alle zusammenhängenden Erze derselben Sorte ab, sobald eines abgebaut wird.
Nur clientseitig. Taste V schaltet die Mod an/aus.

BAUEN
1. JDK 25 installieren (z. B. Temurin 25).
2. Gradle 9.6.0 installieren (https://gradle.org/install/).
3. Windows: build.bat doppelklicken | Linux/Mac: ./build.sh
4. Fertige Mod: build/libs/clientveinminer-1.0.0.jar (NICHT die -sources.jar)

INSTALLIEREN
- Fabric Loader 0.20.0 + Fabric API 0.161.0+26.3 installieren
- clientveinminer-1.0.0.jar in den mods-Ordner legen
